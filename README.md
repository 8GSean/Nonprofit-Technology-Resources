# Nonprofit Technology Resources

A curated collection of programs that provide meaningful value to nonprofits, charities, educational organizations, and community groups.

## TechSoup

The primary gateway to nonprofit technology programs.

* Nonprofit validation accepted by many vendors
* Access to Microsoft, Adobe, Zoom, and other nonprofit offers
* Available internationally through local partners

https://www.techsoup.org/

Israel:
https://www.techsoupisrael.org.il/

## Slack for Nonprofits

Slack offers one of the most substantial nonprofit discounts currently available.

* Free Slack Pro for organizations with up to 250 members
* 85% discount for larger organizations
* Removes message history limits and unlocks Pro features

https://slack.com/help/articles/204368833-Apply-for-the-Slack-for-Nonprofits-discount

## Google for Nonprofits

Google's nonprofit program combines several useful services under a single application.

Includes:

* Google Workspace for Nonprofits
* Google Ad Grants
* YouTube Nonprofit Program
* 100 TB Google Drive storage
* Google Maps Platform benefits

https://www.google.com/nonprofits/

## Canva for Nonprofits

Canva Pro is available at no cost for eligible nonprofits.

* Team collaboration
* Brand management tools
* Marketing, fundraising, and educational materials

https://www.canva.com/canva-for-nonprofits/

## GitHub for Nonprofits

Useful for technical nonprofits, makerspaces, STEM education, and open-source projects.

Benefits include:

* GitHub Team
* GitHub Enterprise discounts
* Security and CI/CD tooling
* Open-source collaboration tools

https://github.com/solutions/industry/nonprofits

## Microsoft for Nonprofits

Microsoft provides grants and discounted licensing for eligible organizations.

Potential benefits include:

* Microsoft 365 grants
* Azure credits
* Microsoft Teams
* Security and device management tools

https://www.microsoft.com/nonprofits

## Goodstack

A verification platform used by a growing number of nonprofit programs.

Useful for:

* Google for Nonprofits verification in many regions
* Access to selected nonprofit software offers
* Eligibility for certain fundraising and partner programs

Goodstack itself is not the benefit; access to partner programs is.

https://goodstack.org/
